# Zen Retro Game Collection

This project archives the previous experiments in the `_archive` folder and provides a simple landing page with links to retro style web games. Each game is implemented as a single HTML file with inline CSS and JavaScript so it can be hosted easily on GitHub Pages.

## Current Games

- **Coin Collector** – Move the square with the arrow keys and grab the coins that appear.
- **Paddle Ball** – Control the paddle with your mouse and keep the ball in play.

## Planned Game Ideas

- Brick Breaker
- Space Invaders clone
- Simple platformer
- Endless runner
- Puzzle slider

Feel free to build on these ideas and expand the collection!
